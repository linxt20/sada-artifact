# Baseline (skill_off) agentic augmentation prompt

Source of truth: `4_code/benchmark/augmenter/run_skill_off_agentic_augment.py (_agent_prompt)`

Generated by `3_experiments/_extract_prompts.py`. Do not edit by hand;
edit the source and re-run the extractor.

This is the whole instruction the skill_off condition receives. It
constrains only the deliverable's CSV format, never what the columns
should be, so it leaks none of the operator's analytical guidance.

---

```text
You are working in the current directory.

`input.csv` is a table.

Analytical query:
{analytical query}

Task: add new columns to this table so that it can help answer that query, and write the result to `augment.csv` in this directory.

Requirements for `augment.csv`:
- It must contain all original rows, in their original order, with all original columns unchanged.
- It must contain at least one new column beyond the original ones.
- Every new column must have a value for every row.
- It must be valid CSV: any field containing a comma, a quote character, or a newline must be quoted and escaped accordingly.

Everything else -- what the new columns are, how you determine their values, and how you go about it -- is your decision.

When you are done, reply with a one-paragraph summary of what you added and why.
```
